Online Examination System

📌 Project Overview

The Online Examination System is a Java-based application designed to provide a simple and efficient platform for conducting online examinations. It allows users to log in, manage their profile, attend examinations, and view their results.

This project was developed as Task 4 of my Java Development Internship at Oasis Infobyte.

🚀 Features

* User login
* User profile management
* Online examination
* Multiple-choice questions
* Exam result display
* Simple and user-friendly interface
* Easy navigation between different sections

🛠️ Technologies Used

* Java
* Java Swing
* Object-Oriented Programming (OOP)

📂 Project Structure

* Main.java – Main entry point of the application
* LoginFrame.java – Handles user login
* ProfileFrame.java – Displays and manages user profile information
* ExamFrame.java – Provides the online examination interface
* ResultFrame.java – Displays the examination results

💡 What I Learned

While developing this project, I gained practical experience in:

* Java programming and OOP concepts
* Creating graphical user interfaces using Java Swing
* Handling user input and events
* Managing different application screens
* Implementing an online examination workflow
* Displaying and calculating examination results
