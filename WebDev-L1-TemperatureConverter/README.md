# Temperature Converter

## Project Overview

This is a Temperature Converter web application developed using HTML, CSS, and JavaScript. The application allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin quickly and accurately.

## Features

* Convert Celsius to Fahrenheit and Kelvin
* Convert Fahrenheit to Celsius and Kelvin
* Convert Kelvin to Celsius and Fahrenheit
* Simple and user-friendly interface
* Instant temperature conversion
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

* index.html
* style.css
* script.js
* temperatureconverter.png

## How to Run

1. Download or clone the project.
2. Open the `index.html` file in any web browser.
3. Enter a temperature value and select the conversion type.
4. View the converted result instantly.

## Output

The application successfully converts temperature values between different units with accurate results.
