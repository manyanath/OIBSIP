Online Reservation System

📌 Project Overview

The Online Reservation System is a Java-based application designed to manage reservations efficiently. It allows users to create, view, and cancel reservations through a simple and user-friendly interface.

This project was developed as Task 1 of my Java Development Internship at Oasis Infobyte.

🚀 Features

* Create a new reservation
* View reservation details
* Cancel an existing reservation
* Store and manage reservation information
* Database connectivity for data management
* Simple and easy-to-use interface

🛠️ Technologies Used

* Java
* MySQL
* JDBC
* Object-Oriented Programming (OOP)

📂 Project Structure

* Main.java – Main entry point of the application
* Reservation.java – Handles reservation-related data
* ReservationForm.java – Provides the reservation form/interface
* CancellationForm.java – Handles reservation cancellation
* DBconnection.java – Establishes database connectivity
* DatabaseSetup.java – Sets up the required database and tables

While developing this project, I gained practical experience in:

* Java programming and OOP concepts
* Connecting Java applications with MySQL using JDBC
* Handling user input and application logic
* Performing database operations
* Building a functional real-world application
